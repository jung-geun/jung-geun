### 안녕하세요, jung-geun입니다 👋

클라우드 인프라와 AI 플랫폼, 일상에서 사용하는 애플리케이션을 만듭니다. OpenStack·Kubernetes 운영부터 개발자 도구와 사용자 앱까지 연결하는 데 관심이 있습니다.

독립적인 오픈소스 프로젝트 **[Afterglow](https://github.com/openstack-afterglow)**에서 OpenStack 대시보드와 다양한 클라우드 서비스를 개발하고 있습니다.

[기술 블로그](https://blog.pieroot.xyz) · [Afterglow 조직](https://github.com/openstack-afterglow) · [운영 중인 서비스](https://cloud.dmslab.re.kr)

| 프로젝트 | 주요 내용 |
| :--- | :--- |
| **[Afterglow](https://github.com/openstack-afterglow/openstack-afterglow)** | Horizon·Skyline을 대체하는 것을 목표로 하는 OpenStack 관리 대시보드. |
| **[Drover](https://github.com/openstack-afterglow/drover)** | OpenStack 기반 Kubernetes·k3s 클러스터 프로비저닝. |

| **[Lumen](https://github.com/openstack-afterglow/lumen)** | 모델 제공자 라우팅, 도구 연동과 지속 가능한 실행 상태를 제공하는 AI 채팅·에이전트 인프라. |
| **[SIFT](https://github.com/jung-geun/SIFT)** | 온디바이스 분석과 선택형 이메일·캘린더 연동을 제공하는 할 일 관리 앱. |

### 주로 다루는 기술

- **클라우드·인프라** — OpenStack, Kubernetes, k3s, Ceph, Docker, Linux, Kolla-Ansible.
- **플랫폼·자동화** — Python, FastAPI, 서비스 API, 프로비저닝, CI/CD, 모니터링.
- **AI·애플리케이션** — LLM·에이전트 런타임, TypeScript, Swift, 온디바이스 AI.

Notion 기반 기술 노트 **[monolog](https://github.com/jung-geun/monolog)**도 개발하며, **[블로그](https://blog.pieroot.xyz)**에 개발·운영 경험을 기록합니다.
