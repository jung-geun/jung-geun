### Hi, I'm jung-geun 👋

I build cloud infrastructure, AI platforms, and practical applications — connecting OpenStack and Kubernetes operations with the tools developers and end users interact with.

I'm building **[Afterglow](https://github.com/openstack-afterglow)**, an independent open-source OpenStack dashboard and ecosystem of cloud services.

[Technical blog](https://blog.pieroot.xyz) · [Afterglow organization](https://github.com/openstack-afterglow) · [Live deployment](https://cloud.dmslab.re.kr)

### What I'm building

| Project | Focus |
| :--- | :--- |
| **[Afterglow](https://github.com/openstack-afterglow/openstack-afterglow)** | An alternative to Horizon and Skyline for managing OpenStack clouds. |
| **[Drover](https://github.com/openstack-afterglow/drover)** | Kubernetes / k3s cluster provisioning on OpenStack. |
| **[Palimpsest](https://github.com/openstack-afterglow/palimpsest)** | Reusable runtime layers, VM artifacts, and declarative local VM workflows. |
| **[Lumen](https://github.com/openstack-afterglow/lumen)** | AI chat and agent infrastructure with provider routing, tools, and durable execution. |
| **[SIFT](https://github.com/jung-geun/SIFT)** | Task management with on-device analysis and optional email and calendar connections. |
| **[NFD2NFC](https://github.com/jung-geun/NFD2NFC)** | Korean filename normalization tools for the web, CLI, and macOS. |

### Areas I work in

- **Cloud & infrastructure** — OpenStack, Kubernetes, k3s, Ceph, Docker, Linux, Kolla-Ansible.
- **Platforms & automation** — Python, FastAPI, service APIs, provisioning, CI/CD, observability.
- **AI & applications** — LLM and agent runtimes, TypeScript, Swift, on-device AI.

I also build **[monolog](https://github.com/jung-geun/monolog)**, a Notion-backed technical notebook, and share engineering notes on my **[blog](https://blog.pieroot.xyz)**.
